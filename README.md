# Spring Boot Student Management API

A RESTful API for managing student records built with Spring Boot.

## 🚀 Features
- Add, View, Update, Delete Students (CRUD)
- RESTful API endpoints
- Spring Boot + Maven
- In-memory storage (easy to extend to MySQL)

## 🛠️ Tech Stack
- Java 17
- Spring Boot 3.x
- Maven
- Spring Web
